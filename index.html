Direct-Acting vs. Reverse-Acting Actuators
Direct-acting actuator: air pressure applied above the diaphragm pushes the stem down as pressure increases. On a normally-seated (push-down-to-close) body, this closes the valve — air pressure is what closes it, so it's called Air-to-Close (ATC). Losing air lets the spring push the stem back up, so it fails open (FO).
Reverse-acting actuator: air pressure applied below the diaphragm pushes the stem up as pressure increases, opening the same style of body. Air pressure is what opens it, so it's called Air-to-Open (ATO). Losing air lets the spring push the stem back down, so it fails closed (FC).
The overall fail-safe behavior of a valve is set by both the actuator's action (direct/reverse) and the valve body's seating style together — the same actuator can give a different fail action on a differently-seated body. Always confirm the actual fail position on the specific valve, not just the actuator type.

Safety-critical: the fail position is chosen based on which state is safer for the process if air/power is lost — e.g. an ESD valve on a fuel line is typically fail-closed; a vent or relief path is typically fail-open. Always verify against the specific P&ID/datasheet, not assumption.
Control Valve Working Principle
A controller sends a 4-20mA signal to an I/P converter, which converts it to a 3-15psi pneumatic signal. The positioner compares this against actual valve position and adjusts actuator air pressure. The actuator moves the stem, which moves the plug, changing flow through the valve — closing the loop with a position feedback signal back to the controller.
Actuator (diaphragm) — provides force to move the stem
Positioner — ensures accurate valve positioning
Stem — transmits motion from actuator to plug
Plug — regulates flow by opening/closing against the seat
Seat ring — provides tight shut-off
Valve body — contains the flow, connects to the pipeline
Flow characteristics
Linear — equal change in travel produces equal change in flow
Equal percentage — equal change in travel produces increasing change in flow
Quick opening — large change in flow occurs early in the travel
Common valve body types
Globe — good throttling control, moderate cost
Ball — tight shutoff, fast quarter-turn action
Butterfly — compact, lightweight, good for large pipe sizes
Rotary plug — high rangeability, good throttling in demanding service

ISO 10816 (superseded by ISO 20816) classifies broadband RMS vibration velocity (mm/s, 10-1000Hz) on bearing housings into 4 severity zones. Thresholds depend on machine group — shown below for Group 2 (medium machines, 15-75kW, rigid foundation), the most common industrial case.
ZoneVelocity (mm/s RMS)Meaning
Aup to ~1.4Good — newly commissioned/reconditioned
B~1.4 to 2.8Satisfactory — acceptable for unrestricted long-term operation
C~2.8 to 4.5Unsatisfactory — short-term OK, plan a repair
Dabove ~4.5Unacceptable — damage likely, act immediately
These numbers are for Group 2 machines on a rigid foundation only — Group 1 (small, <15kW), Group 3/4 (large, or flexible foundations), reciprocating machines (ISO 10816-6), and machine tools (ISO 10816-8) all have different thresholds. Always confirm the correct group/sub-part for the actual machine before judging a reading. A recommended alarm setpoint sits at the B/C boundary, and a trip setpoint at the C/D boundary.
Velocity is used (not displacement or acceleration) because it correlates best with the fatigue-causing energy across normal industrial running speeds.
Grounding/earthing protects people and equipment and gives noise a return path. Bonding ties conductive parts together so they sit at the same potential, preventing dangerous voltage differences.
Typical Resistance Targets
General equipment grounding: ≤25Ω (many codes' minimum) — ≤5Ω or ≤1Ω is common for critical/substation grounds
Intrinsically-safe system grounding: typically ≤1Ω, per the specific IS system's documentation
Sensitive electronics/instrumentation: often ≤5Ω target where practical
Exact required values vary by code/standard/site spec — treat these as general orientation, not a pass/fail spec for a specific job.
Single-Point vs Multi-Point Grounding
Single-point: all grounds tie back to one common reference point. Avoids ground loops — preferred for sensitive low-frequency instrumentation/signal cable shields.
Multi-point: equipment grounds locally to the nearest ground plane/structure at many points. Better for high-frequency noise control — common in large facilities and for equipment frames/racks.
Common Test Methods
Fall-of-potential (3-point) test — the traditional, most accurate method for a ground rod/system
Clamp-on ground resistance test — no need to disconnect the ground, faster for routine checks, best on multi-grounded systems
An orifice plate's bore is sized relative to the pipe using the beta ratio (β):
β= d ÷ D (bore diameter ÷ pipe internal diameter)
Typical usable range: β ≈ 0.2 to 0.75
Low β (~0.2-0.4): higher ΔP for a given flow, better turndown/sensitivity, but more permanent pressure loss
High β (~0.6-0.75): lower permanent pressure loss, but less sensitive at low flow
Pressure Tap Types
Flange taps — most common in industry, taps 1" from each face of the plate
Corner taps — taps right at the plate corners, common for smaller pipe sizes
D and D/2 taps (vena contracta) — upstream tap 1×D, downstream tap at ~0.5×D where the vena contracta forms
Pipe taps — furthest from the plate (2.5D upstream, 8D downstream), less common, higher recoverable-loss accuracy tradeoffs
Sizing per ISO 5167 / ASME MFC-3M requires knowing the fluid properties, required flow range, and acceptable permanent pressure loss — use a proper sizing calc or vendor software for a final design, this is orientation only.
Bolt torque converts to clamping (preload) force via: T = K × D × F
T = target torque
K = nut factor (friction — depends heavily on lubrication)
D = nominal bolt diameter
F = target bolt preload force (from required gasket seating stress)
Typical K-Factor Ranges
Well-lubricated (moly/copper/nickel anti-seize): K ≈ 0.13-0.16
Lightly lubricated (machine oil): K ≈ 0.18-0.20
Dry / unlubricated threads: K ≈ 0.20-0.30
The same torque wrench setting can produce roughly 2× different actual clamp load depending only on whether threads are lubricated, dry, or corroded — the lubricant condition matters more than almost anything else in this calculation.
Tightening Sequence
Use a star/cross pattern (never sequential around the flange), applied in stages — typically ~30% → 60% → 100% of target torque — to keep gasket compression even and avoid flange rotation or misalignment.
⚠️ This is not a substitute for a real torque value. Actual target torque depends on flange class, gasket type, bolt material/grade, and lubricant — always use the project's engineering spec or the gasket/flange manufacturer's torque chart (e.g. per ASME PCC-1) for the actual number used on a real joint.

Transmitter Wiring
4-20mA is a DC current-loop signal — the industry standard for transmitting a process variable because it's simple, reliable, and highly immune to electrical noise over long distances.
4mA = 0% (LRV)
20mA = 100% (URV)
Typical loop supply: 24VDC (12-36VDC device dependent)
NAMUR NE43 fault indication
<3.6mA — under-range / loop fault
4-20mA — normal operating range
>20.5/21mA — over-range / diagnostic
Starting at 4mA (not 0) means the loop can still power a 2-wire transmitter AND distinguish a real fault (0mA/dead loop) from a valid 0% reading.

Noise immunityExcellentLower — more susceptible
DistanceLong (minimal loss)Short (<100m typical)

Analog: continuous signal, infinite values within a range (4-20mA, 0-10V, mV). More susceptible to noise/distortion; distance depends on cable/signal type.
Digital: discrete signal, only two states (0/1, OFF/ON), or structured data over a protocol (Modbus, Profibus, HART, Ethernet/IP). Better noise immunity and error detection, generally supports longer distances with repeaters.
Range is the measurement interval an instrument is calibrated for — from LRV to URV. It defines the instrument's overall capability.
Span is the numeric difference between URV and LRV — it tells you the size of that measurement window.
Range = LRV to URV (e.g. 0°C to 100°C)
Span = URV − LRV (e.g. 100 − 0 = 100°C)
LRV isn't always 0 — e.g. LRV=50°C, URV=150°C gives a range of "50 to 150°C" but a span of 100°C.
Zero error: deviation at the LOWER range point (0%/LRV) only. Shifts the whole calibration curve up or down, parallel to the ideal line — doesn't change the slope. Usually from improper zero adjustment or sensor offset.
Span error: deviation at the UPPER range point (100%/URV) only. Changes the slope of the calibration curve — zero point stays correct. Usually from incorrect span adjustment or component drift.
Example: reads 0.5 bar at true 0 bar (range 0-10 bar) → Zero Error = +0.5 bar (5% of span)
Example: reads 9.5 bar at true 10 bar → Span Error = −0.5 bar (5% of span)
2-wire: power and signal share the same two wires (the 4-20mA loop itself powers the transmitter). Simplest wiring, most common for pressure/level/temperature transmitters.
3-wire: separate power supply wires, with the signal sharing a common return. Common on proximity/photoelectric sensors.
4-wire: completely separate power and signal circuits. Used for flow meters, gas analyzers, and other transmitters that need more power than a 2-wire loop can supply.
Smart vs Conventional Transmitters
Smart transmitters add digital communication (HART, Fieldbus, Profibus PA, Modbus) on top of the 4-20mA signal, giving remote configuration, advanced diagnostics, and generally higher accuracy. Conventional transmitters give 4-20mA only, with configuration limited to physical zero/span adjustments and little to no self-diagnostics.

Zone Classification
IS vs Explosion Proof
Zener Barrier
Galvanic Isolator
Zones classify how often/long an explosive gas atmosphere is present:
Zone 0 — present continuously or for long periods (highest risk). Typical: inside tanks/vessels
Zone 1 — likely to occur in normal operation. Typical: around tank openings, pump seals, flanges, valves
Zone 2 — not likely in normal operation, and if it occurs, only briefly. Typical: under roofed areas near low-leak-probability equipment
Actual classification depends on process, ventilation, leak sources, and operating conditions — always refer to the site's formal risk assessment (e.g. IEC 60079-10-1), not a rule of thumb.
Intrinsic Safety (Ex i): equipment is designed so it simply can't release enough electrical/thermal energy to ignite a hazardous atmosphere. Low power only (signals/instruments) — but suitable for Zone 0, 1, and 2. Easy maintenance, can often be worked on live under approved procedures.
Explosion Proof (Ex d): equipment is enclosed in a flameproof housing that can contain an internal explosion and stop it from igniting the surrounding atmosphere. Handles high power (motors, panels) but only suitable for Zone 1 and 2 — not Zone 0. Enclosure generally shouldn't be opened while energized.
Example marking: Ex ia IIC T4 Ga (intrinsic safety, highest category)
Example marking: Ex d IIC T6 Gb (explosion proof)
Choose Ex i for low-power instrumentation/signals in continuous hazardous atmospheres. Choose Ex d for high-power equipment (motors, junction boxes, lighting) in harsher, less-continuous zones.
A Zener barrier limits voltage and current using a Zener diode, protecting intrinsically-safe circuits from excess energy reaching the hazardous area.
Normally the Zener diode sits in reverse bias (not conducting). If voltage tries to exceed the safe limit, it conducts and clamps the voltage to a safe value (Vz) — a fuse protects the diode itself from being overstressed in the process.
Requires dedicated, reliable earth grounding to work safely
Does NOT provide electrical isolation, and does NOT eliminate ground loops
Lower cost, simple, no power supply required
A galvanic isolator transfers an analog/digital signal while electrically isolating input and output circuits completely — using a transformer, opto-isolator, or capacitive coupling. No direct electrical connection between the two sides.
No dedicated grounding required
Eliminates ground loops and reduces electrical noise
Typical isolation: 1.5kV to 4kV
Higher cost than a Zener barrier, but better signal quality
Zener barrier vs galvanic isolator: Zener barrier is cheaper and needs dedicated grounding but gives no isolation and doesn't fix ground loops. Galvanic isolator costs more but needs no dedicated ground, gives true isolation, and eliminates ground loops/noise — better choice where signal quality or grounding is a challenge.

Star (Y): one end of all three phase windings joins at a common neutral point. Each phase only sees line voltage ÷ √3, giving lower starting current and torque (~1/3 of delta) — used to reduce inrush current when starting a motor.
Delta (Δ): the end of one phase connects to the start of the next, forming a closed loop. Each phase sees full line voltage, giving higher starting current and full torque — used for normal running once the motor is up to speed.
Star: lower starting current, used for starting
Delta: higher torque, used for running

PNP (Sourcing): the sensor's output provides +24V — current flows OUT of the sensor, into the PLC input, and back to 0V. Common in Europe and most of Asia (IEC standard). Pair a PNP sensor with a sinking PLC input.
NPN (Sinking): the sensor's output pulls to 0V — current flows from the PLC's +24V, into the sensor, and to ground. Common in Japan and some legacy Asian equipment. Pair an NPN sensor with a sourcing PLC input.
Memory tip: PNP "Provides (+)" → Sources. NPN "Not providing (+)" → Sinks.
Common mistakes: mismatching sensor/PLC input type (no signal), reversing +24V/0V, floating 0V (no common reference), mixing PNP and NPN sensors on the same input card. Always check the PLC input type matches the sensor's output type before wiring.

Compact PLC: all components (CPU, I/O, power) built into a single unit. Lower cost, quick to install, but fixed configuration and limited expansion — if one part fails, the whole unit may need replacing.
Modular PLC: built from separate modules (CPU, I/O, power, comms) that can be added as needed. Higher cost and more setup time, but highly flexible, easy to expand, and modules can be swapped individually for troubleshooting.
Compact: small/simple applications, fixed I/O count
Modular: large, complex, scalable applications
Safety PLC: certified to functional safety standards (IEC 61508, IEC 62061, ISO 13849). Redundant hardware, self-diagnostics, fail-safe design — built to keep operating safely even when a fault occurs. Used for E-stop, safe shutdown, safety-critical interlocks.
Standard PLC: built for general automation/control (sequencing, timing, counting) — not certified for dedicated safety functions and not guaranteed to fail to a safe state.
Rule of thumb: use a Safety PLC wherever a failure could cause injury, loss of life, or major equipment damage; standard PLC for everything else.

TCP vs UDP
TCP — connection-based; both ends handshake (SYN → SYN-ACK → ACK) before data flows, and every packet is acknowledged and re-sent if lost. Reliable and ordered, but has more overhead/latency. Used where data loss isn't acceptable.
UDP — connectionless; packets are just sent with no handshake and no guarantee of delivery or order. Lower latency and overhead, but the application has to tolerate (or handle) dropped/out-of-order packets. Used where speed matters more than perfection.
TCP: web, email, file transfer, Modbus TCP
UDP: streaming, broadcast, discovery, DNS

DCS (Distributed Control System): used for complex, continuous process control inside a plant. Control intelligence is distributed across multiple controllers on a high-speed industrial network. High reliability/redundancy, handles large numbers of data points with fast response, advanced control (PID, cascade, predictive).
SCADA (Supervisory Control and Data Acquisition): used to monitor and control remote locations spread over a wide area. One master station monitors multiple remote sites (RTU/PLC) via WAN/cellular/radio/satellite. Basic control — mostly monitoring, alarming, data logging.
DCS: refineries, chemical plants, power plants — continuous process
SCADA: water/oil&gas/power distribution — geographically dispersed sites
An RTU (Remote Terminal Unit) is an intelligent interface between field instruments and the control center — collects field data, processes it, and communicates with SCADA.
Measure — collects data from sensors/digital inputs
Acquire — converts/filters raw signals into usable data
Process — performs logic, calculations, event detection
Communicate — sends data to SCADA, receives control commands
Control — executes commands on field devices (DO/AO)
Communication options: cellular (4G/5G), Ethernet (TCP/IP), fiber optic, radio (VHF/UHF), satellite — chosen based on how remote/dispersed the site is.
Open loop: no feedback path — the process variable is never compared for error. Output depends only on input and the system itself; it can't automatically correct disturbances. Example: a timer-based washing machine runs a fixed time regardless of how clean the load actually is.
Closed loop: output is measured and fed back to a comparator, which detects any error between setpoint and actual value, and the controller adjusts to minimize it. More accurate, self-correcting. Example: a room thermostat maintains a set temperature by continuously comparing actual vs desired.
Open loop: timer-based systems (traffic light timer, toaster)
Closed loop: thermostat, cruise control, pressure regulator

Connect Device (Bluetooth / WiFi / HART)
Read before connecting: Bluetooth support depends on your instrument's actual hardware — this works with devices that expose a serial/UART-style Bluetooth LE service (a common pattern, but not universal). WiFi devices usually need to be reachable over plain HTTP, which browsers block from an HTTPS site like GitHub Pages unless the device also supports HTTPS. The HART tool below builds correctly-framed/checksummed command bytes, but writing range values (URV/LRV) changes a live transmitter's calibration — verify everything against your transmitter's manual and test on a bench setup before using on an installed, in-service device.

Report Sync (Google Sheets / Excel)
How this actually works: a real "sign into your Google/Microsoft account" connection needs a registered backend app, which this static site doesn't have. Instead, this uses a webhook URL — a link to a small script you set up once, that this app sends report data to, which then writes a row into your actual sheet/workbook. Same end result (data lands in your spreadsheet automatically), just set up via a link instead of a login.

Not linked

Excel

Not linked
Use a Power Automate flow with an HTTP-request trigger that adds a row to an Excel Online table (OneDrive/SharePoint), then paste the flow's HTTP POST URL below. Zapier/Make.com webhooks pointed at Excel work the same way.
Once a webhook is saved here, a "Sync" button appears next to Export on Field Notes, Field Report, Commissioning, Loop Check, and Setpoints — tapping it sends that record to whichever webhook(s) you've linked. Browser security means this app can't confirm the row actually landed (the response can't be read back) — check your sheet/workbook directly the first time to confirm it's working, using Send Test Row above.
